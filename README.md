# Pumiput Chaichat — Personal Site

**TH:** เว็บส่วนตัวสองภาษา เล่าเรื่องผ่านภาพถ่ายก่อน แล้วค่อยเล่าเรื่องงาน
**EN:** A bilingual personal site that introduces me through places and light first, and work second.

`PHP` · `HTML5` · `CSS3` · `Vanilla JavaScript`

---

## 🇹🇭 ภาษาไทย

### แนวคิด

พอร์ตโฟลิโอของ developer ส่วนใหญ่หน้าตาเหมือนกันหมด — hero gradient, การ์ดเรียงกัน, ไอคอน tech stack เรียงเป็นแถว ผมเลยอยากลองอีกทาง

เว็บนี้เป็น **Cinematic Personal Journal** — หน้าแรกเป็นบทๆ ของภาพถ่ายเต็มจอ ตัวหนังสือสั้นๆ วางเฉพาะตรงที่ภาพมีพื้นที่ว่าง คนที่เข้ามาควรจำ "บรรยากาศ" ได้ก่อน แล้วค่อยรู้ว่านี่คือเว็บของใคร

### หลักที่ยึด

- **ภาพคือโครงสร้างของหน้า ไม่ใช่ของตกแต่ง** — layout เดินตามภาพ ไม่ใช่เอาภาพมาใส่ในกล่อง
- **ตัวหนังสือน้อย แต่เป็นคำของตัวเอง** ไม่ใช้ภาษาการตลาด
- **ไทยและอังกฤษเท่าเทียมกัน** ไม่ใช่ภาษาหนึ่งเป็นของแถม
- **โทนมืดใช้ near-black ที่เป็นกลาง** ไม่ใช้เขียวเข้ม
- **เคารพ `prefers-reduced-motion`** และใช้คีย์บอร์ดเดินได้ครบ
- **ไม่ใช้เฟรมเวิร์ก** — PHP, HTML, CSS, JavaScript ล้วน ตั้งใจให้เป็นข้อจำกัดที่บังคับให้คิดเรื่องพื้นฐานให้ดี

### หน้าในเว็บ

```
index.php      → หน้าแรก — บทของภาพถ่าย
about.php      → เกี่ยวกับผม
portfolio.php  → ผลงาน
projects.php   → โปรเจค
contact.php    → ติดต่อ (Facebook / Instagram)
includes/      → ส่วนประกอบที่ใช้ซ้ำ
assets/        → ภาพและสไตล์
```

## 🇬🇧 English

### The idea

Most developer portfolios look the same — gradient hero, a grid of cards, a row of tech-stack icons. I wanted to try the other direction.

This is a **cinematic personal journal**. The home page is a sequence of full-viewport photographic chapters, with short lines of copy placed only where an image leaves room. The goal is that a visitor remembers the atmosphere first, and learns whose site it is second.

### Principles

- **Photography is the page structure, not decoration** — the layout follows the images, not the reverse
- **Little copy, but in my own voice** — no marketing language
- **Thai and English are equals**, not one bolted onto the other
- **Dark sections use neutral near-black**, never dark green
- **`prefers-reduced-motion` respected**, full keyboard navigation
- **No framework** — PHP, HTML, CSS, and vanilla JS, as a deliberate constraint that forces the fundamentals to be right

### Pages

```
index.php      → home — the photo chapters
about.php      → about me
portfolio.php  → portfolio
projects.php   → projects
contact.php    → contact (Facebook / Instagram)
includes/      → shared components
assets/        → images and styles
```
